# SoulSonus brand assets

The vectors are the source. The PNGs are renders of them, regenerated by
`npm run brand:render`. Change the SVG, re-run, commit both.

## Files

| | |
|---|---|
| `soulsonus-mark.svg` | the mark alone — gradient edge, dark core, amber S |
| `soulsonus-wordmark.svg` | SOULSONUS, the gradient the app uses (amber-300 → slate-100 → cyan-300) |
| `soulsonus-wordmark-two-tone.svg` | SOUL in slate-100, SONUS in amber-500 — the treatment in the new layout |
| `soulsonus-lockup.svg` | mark + wordmark + DAW & INTELLIGENCE |
| `soulsonus-palette.png` | the whole colour system on one sheet |
| `palette.json` | the same values, machine-readable |

PNG sizes: the mark at 1024 / 512 / 256 / 128 / 64 / 32; the wordmarks at
2100 / 1400 / 700; the lockup at 2820 / 1880 / 940. Everything is transparent.
The `-on-dark` twins are the same art flattened onto `#020617`.

**Use the two-tone wordmark on light backgrounds.** The gradient wordmark runs
through `slate-100` in the middle, which disappears on white. It is designed
for the studio, and the studio is `slate-950`.

## The colour system, in one paragraph

Every surface sits on `slate-950`. `slate-800` draws every border in the app —
it is the single most used token in the codebase. **Amber is the creator**:
record, export, tap, the creator's own actions and their own material.
Cyan is instrument, MIDI and workstation. Emerald is ready and healthy.
Purple is collaboration, the native brain and vocal material. Pink is writing.
Rose is the only colour that means something went wrong, so nothing decorative
is ever allowed to use it.

Full table with roles and usage counts: `soulsonus-palette.png` / `palette.json`.

## The font

The app sets `font-mono`, which resolves to whatever monospace the creator's
machine provides — Consolas on Windows, SF Mono on a Mac. The committed PNGs
were rendered in a Linux container, so their glyphs are DejaVu Sans Mono. The
shapes will differ slightly from what you see in the running studio. If that
matters for a particular use, re-render on the machine that will be looking at
it, or set a real licensed face in the SVG before rendering.
