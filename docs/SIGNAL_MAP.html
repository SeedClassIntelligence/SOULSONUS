Where the leverage is

Ordered by value returned per unit of work, given what already exists on disk.

  1. Plug in the loudness engine.

    The Master room's headline numbers become real measurements. The DSP is written and correct; it needs an audio-buffer render of the master bus and one call site. Nothing new to design.

  2. Plug in the encoders.

    Export stops writing text files. audioEncoders.ts already does 24-bit WAV and FLAC; it needs the same rendered buffer as above, which makes these two one project rather than two.

  3. Build the master bus graph.

    The seven mastering stages and the mix room's EQ commit both fail for the same reason: there is no processing chain on the master bus. One graph makes both real and turns the existing parameter UI into controls.

  4. Add project persistence.

    Capture now produces real performances, and a reload throws them away. Until this exists, nothing a creator makes survives, and the "16-note default" confusion recurs every session.

  5. Make Extract Stems use the take.

    The classifier already labels every onset by sound type. Stem extraction can read those labels instead of writing the demo pattern — this is now a small change rather than a new capability.

  6. Replace or remove the Mix advisor.

    The masking proposals cannot be repaired by tuning; they are literals. Either compute real cross-channel masking from the rendered buses, or take the panel out. Leaving confident percentages over an empty canvas is the costliest kind of wrong.

  7. Put tsc --noEmit in CI.

    Cheapest item on the list. It would have caught both crashes before deploy.

What "verified" means here

Working means a live test drove the real app and observed real data changing — synthetic audio through Chromium's fake capture device, state read from React's committed fiber tree, cross-checked against the DOM. Decorative means the value shown is a literal in the source, or the control constructs no audio nodes when operated. Unplugged means a genuine implementation exists that no file imports. Not built means neither exists. Claims carried over from earlier passes were re-checked against the current branch rather than trusted.
