What "Working" means here — and what it used to miss

Every row below describes main at the commit named above, which is the commit Netlify builds. That distinction matters: for most of this project's life the map described a feature branch that had never been merged, so it reported components as working while the deployed site was white-screening on a missing import from before the audit began. The status of a room and the status of the site are different questions, and this map only answers the second one when the two are the same commit.

If the rows here disagree with what you see on the live site, check that first — git log --oneline -1 origin/main against the commit in the header. The stamp names the last code commit the rows describe; this document is committed immediately after it, so the deployed head is normally one commit further on and contains no code the map has not seen.

Where the leverage is

Layers 0 and 1 are complete, and Layer 2 has started — the AUDITION sweep has landed and is recorded above. What remains is ordered by value returned per unit of work, given what already exists on disk.

  1. Captured notes bypass undo.

    A take currently cannot be undone. The history stack is real; capture writes around it.

  2. Bind audio to vocal takes.

    Takes, ratings and comp segments are real records with no audio attached, and take playback does not exist. Persistence now stores one take per session, so this is the next step to make comping mean anything.

  3. Arrangement sections.

    Confirmed not built — initial state literal only, no add, rename or delete handler anywhere.

What "verified" means here

Working means a live test drove the real app and observed real data changing — synthetic audio through Chromium's fake capture device, state read from React's committed fiber tree, cross-checked against the DOM. Decorative means the value shown is a literal in the source, or the control constructs no audio nodes when operated. Unplugged means a genuine implementation exists that no file imports. Not built means neither exists. Claims carried over from earlier passes were re-checked against the current branch rather than trusted.
