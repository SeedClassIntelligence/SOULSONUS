Where the leverage is

Layer 0 is complete. What follows is ordered by value returned per unit of work, given what already exists on disk.

  1. Sweep the remaining decorative AUDITION controls.

    One shape, four known locations in the vocal suite: setState(true) → setTimeout → setState(false), no audio. Studio Intelligence shows what a real one looks like — it builds actual audio nodes — so this is a pattern to copy, not to design.

  2. Move the utility drawer row out of StudioCanvas.

    Eight workstations are unreachable from four of six rooms purely because of where the trigger row is rendered.

  3. Lift workspace-local UI state into context.

    Selected tool and bar view reset whenever the canvas unmounts on a switch to rooms 3–6. Narrower than the architecture implied — session data, playback and live capture already survive — so this is a small fix, not a re-architecture.

  4. Point the Room 6 export panel at the real bounce.

    The bounce, encoders and measurement all work; ExportModal and the delivery manifest still write a text file and fabricate URLs. Pure plumbing now.

  5. Per-track EQ.

    Distinct from the bus graph, which is done. lowGain/midGain/highGain are written by the Vocal DSP tab and read by nothing — and the masking analysis now says exactly which bands would need it.

  6. Captured notes bypass undo.

    A take currently cannot be undone. The history stack is real; capture writes around it.

  7. Bind audio to vocal takes.

    Takes, ratings and comp segments are real records with no audio attached, and take playback does not exist. Persistence now stores one take per session, so this is the next step to make comping mean anything.

  8. Arrangement sections.

    Confirmed not built — initial state literal only, no add, rename or delete handler anywhere.

What "verified" means here

Working means a live test drove the real app and observed real data changing — synthetic audio through Chromium's fake capture device, state read from React's committed fiber tree, cross-checked against the DOM. Decorative means the value shown is a literal in the source, or the control constructs no audio nodes when operated. Unplugged means a genuine implementation exists that no file imports. Not built means neither exists. Claims carried over from earlier passes were re-checked against the current branch rather than trusted.
